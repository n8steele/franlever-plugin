# Franlever

Franlever is an AI COO for store operators and franchise teams. This plugin lets Claude read the stores, findings and daily briefs your Franlever role already allows.

## What it does

- Shows which stores need attention today.
- Explains changes in sales, labor, reviews and waste at a store.
- Compares stores over a date range.
- Reads the daily briefs AI COO delivered and where each lever went.

The connection is read-only. It cannot change settings, send messages or mark work complete. Daily monitoring and delivery run in Franlever on your configured schedule.

## Requirements

- A Franlever account with connected data (POS first).
- Franlever workspace assistant access must allow Claude.

## Setup

Add the plugin, then sign in to Franlever when Claude asks. Sign-in uses OAuth with dynamic client registration against `https://app.franlever.com/mcp`. Answers cover only the stores your Franlever role can see.
